# color-diff 要件定義書

## 1. 概要

複数の色を並べて視覚的・定量的に比較できるWebサイト。
色の数値的な差分（色差・コントラスト比など）の確認と、実際のUIパーツに色を適用した見た目の確認を1つの画面で行える。

- **リポジトリ**: color-diff
- **形態**: 静的サイト（サーバーレス、バックエンドなし）
- **作成日**: 2026-08-12

## 2. ターゲットユーザー

| ユーザー | 主な用途 |
|---|---|
| Web開発者・デザイナー | UI配色の検討、WCAGコントラスト確認、デザイントークン選定 |
| 一般ユーザー | 色選び全般（イラスト、印刷、インテリア等）、色の違いの確認 |

一般ユーザーも対象とするため、専門用語（ΔE等）には簡単な説明を添える。

## 3. 機能要件

### 3.1 色の入力・管理

- **デフォルトは2色**でスタートする
- 色は**無制限に追加**できる（追加・削除・並べ替え）
- 入力方法:
  - カラーピッカー
  - テキスト入力: HEX / RGB / HSL（将来: OKLCH, Lab）
  - スポイト取得（ブラウザ標準カラーピッカー内のスポイト機能を利用。独自ボタンは設けない）
- 各色に任意の名前を付けられる（例: "brand-primary"）

### 3.2 定量的比較

選択中の色に対して以下を表示する。

**ペアごとの指標**（2色間の比較。3色以上の場合は選択ペアまたはマトリクス表示）:

- 色差 ΔE（CIEDE2000 を標準、参考として CIE76）
- WCAG 2.x コントラスト比と AA / AAA 判定（通常テキスト・大テキスト別）
- 明度差・彩度差・色相差

**各色ごとの情報**:

- 各色空間での値: HEX / RGB / HSL / Lab / LCH / OKLCH
- 相対輝度
- 値のワンクリックコピー

### 3.3 標準パーツプレビュー（色ごと複製方式）

- 標準UIパーツで構成された**サンプルページ**を1種類用意する
- サンプルページの複製を**色の数だけグリッド状に並べて表示**する（5色なら5つ）
  - 画面幅に応じて折り返すレスポンシブなグリッドレイアウト
- **比較対象パーツを選択**できる。各複製では選択パーツのみがその複製の担当色で描画され、
  それ以外のパーツは全複製共通のニュートラルな標準配色で固定される
  - 例: 「ボタン」を選択 → 色1のボタンのページ、色2のボタンのページ…がグリッドに並び、
    同じ文脈での色の見え方を比較できる
- 比較対象パーツの例:
  - ボタン
  - カード背景
  - 見出しテキスト / 本文テキスト
  - ナビゲーションバー
  - バッジ / アラート
- サンプルページの背景はライト / ダークを切り替えられる
- 選択パーツと隣接色（背景等）のコントラストが不足している複製には警告アイコンを表示する（定量比較との連携）

### 3.4 共有・保存

- **URL共有**: 色・比較対象パーツを含む比較状態をURLクエリパラメータにエンコードし、URLを開けば同じ状態が再現される
- **ローカル保存**: 直近の状態をlocalStorageに自動保存し、再訪時に復元する

### 3.5 インポート・エクスポート

- **インポート**: 各プラットフォームの色定義テキスト（貼り付けまたはファイル選択）から色リストへ取り込む。形式は自動判別
  - Android `colors.xml`（`#AARRGGBB` のアルファは除去、`@color/` のローカル参照は1段解決）
  - iOS Swift コード（`UIColor` / `Color` の red/green/blue コンポーネント、`0xRRGGBB` リテラル）、Asset Catalog `Contents.json`
  - CSS カスタムプロパティ / SCSS 変数 / JSON トークン（`value` / `$value` 対応）/ 「名前: 値」形式のプレーンリスト
  - 既存リストへの「追加」とリストの「置き換え」を選択可能（一度に最大200色）
- **エクスポート**: 色リストを Android XML / iOS Swift（SwiftUI extension）/ CSS 変数 / SCSS 変数 / JSON の各形式で生成し、コピーまたはファイルダウンロード
  - 色名は各形式の命名規則（snake_case / camelCase / kebab-case）に変換し、変換で失われる元の名前はコメントとして併記

### 3.6 スコープ外（将来検討）

- Tailwind設定としてのパレットエクスポート
- APCA（WCAG 3 ドラフト）コントラスト指標
- 画像からの色抽出
- パレットのサーバー保存・ユーザーアカウント

## 4. 非機能要件

- **ホスティング**: 静的ホスティング（GitHub Pages を想定）。ビルド成果物のみで動作すること
- **レスポンシブ**: スマートフォン〜デスクトップに対応
- **パフォーマンス**: 色の変更に対する指標・プレビューの更新は即時（体感遅延なし）
- **アクセシビリティ**: サイト自体がWCAG AA を満たすこと（色比較ツールとしての信頼性に直結）
- **対応ブラウザ**: モダンブラウザ最新版（Chrome / Edge / Firefox / Safari）
- **言語**: 日本語（将来: 英語対応を考慮しUI文言はハードコードしない）

## 5. 技術構成

- **フレームワーク**: React + Vite + TypeScript
- **色計算**: culori（色空間変換・ΔE・コントラスト計算）を第一候補とする
- **状態管理**: React標準（useState / useReducer + Context）から開始。複雑化したら見直す
- **スタイリング**: 実装フェーズで選定（プレビューパーツの動的テーマ適用にはCSS変数を使用する想定）
- **デプロイ**: GitHub Pages（GitHub Actions によるビルド・デプロイ）

## 6. 画面構成（想定）

単一ページ構成:

```
┌──────────────────────────────────────┐
│ ヘッダー（タイトル / 共有URLコピー）        │
├──────────────┬───────────────────────┤
│ 色リスト       │ 比較結果                │
│  ├ 色1        │  ├ 定量比較（表/マトリクス）│
│  ├ 色2        │  └ パーツプレビュー        │
│  ├ 色3        │     対象: [ボタン ▼]      │
│  └ [+ 追加]    │   ┌色1┐ ┌色2┐ ┌色3┐    │
│               │   │ﾍﾟｰｼﾞ│ │ﾍﾟｰｼﾞ│ │ﾍﾟｰｼﾞ│    │
│               │   └──┘ └──┘ └──┘    │
│               │   ┌色4┐ ┌色5┐ (ｸﾞﾘｯﾄﾞ  │
│               │   │ﾍﾟｰｼﾞ│ │ﾍﾟｰｼﾞ│  折返し)  │
│               │   └──┘ └──┘         │
└──────────────┴───────────────────────┘
```

- 色リスト: 入力・追加削除・並べ替え・インポート / エクスポート（モーダル）
- 定量比較: 2色時はペア指標を直接表示、3色以上はマトリクスまたはペア選択
- パーツプレビュー: 比較対象パーツ選択 + 色ごとのサンプルページ複製をグリッド表示

## 7. マイルストーン

| フェーズ | 内容 |
|---|---|
| MVP | 2色比較: 入力（ピッカー/HEX）、ΔE・コントラスト比・色空間値、URL共有 |
| Phase 2 | 無制限色追加、マトリクス表示、パーツ選択 + 色ごと複製プレビュー |
| Phase 3 | localStorage復元、色名管理 |
